## 📋 About

This is my personal portfolio website built with vanilla HTML, CSS, and JavaScript. It serves as an interactive CV showcasing my professional experience, technical skills, certifications, and ongoing cybersecurity projects.

## 🗂️ Sections

- **Hero** — Introduction and current role
- **Skills & Certifications** — Technical skills and verified certifications
- **Experience** — Full work history with responsibilities
- **Projects** — Ongoing cybersecurity and infrastructure labs
- **Contact** — Links and contact information

## 🛠️ Built With

- HTML5 & CSS3 (no frameworks)
- Vanilla JavaScript
- Google Fonts (Syne, DM Sans, Share Tech Mono)
- Hosted via GitHub Pages
